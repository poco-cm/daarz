## Decision 1 — Exactly one agent kind

`accumulator` is the only kind the factory can build. Any other value raises
`ConstructionError`.

Rationale: Order 2 asks for **one** schema. Defining `researcher`, `planner`, or
`observer` kinds now would mean defining names with no construction path behind them —
precisely the decorative pattern the order forbids. Kinds will be added when something
needs to build them.

## Decision 2 — Creation and execution are separate authorities

`AgentFactory.build()` produces a runnable agent but never starts it. Registration in the
civil registry happens only after successful construction, so the registry can never hold
a record for an agent that failed to come into existence.

## Decision 3 — Article II is enforced in two places, not one

`authorised_by` beginning with `agent:` is rejected by `AgentSpec` at validation time and
again by `AgentRegistry.register()` at record time. Duplication is deliberate: the
constitutional prohibition on self-replication should not depend on a single call site
remaining correct.

## Decision 4 — The kill switch is consulted before every cycle, without exception

`ExecutionLoop.run()` calls `kill_switch.assert_clear()` at the top of each iteration,
before perception. There is no fast path, no sampling interval, and no cycle count at
which the check is skipped. An agent with an already-engaged switch completes zero cycles.

## Decision 5 — The loop exposes an observer hook

`ExecutionLoop.observe()` was added in this phase although nothing consumed it yet, so
that phase 3 logging could attach to the real loop instead of a parallel reimplementation
of it. This is the one forward-looking hook in the phase; it is exercised by the birth
demonstration itself, so it is not dead code.

## Decision 6 — The registry is file-backed, and the empty case is named

`AgentRegistry._load()` returns a **named** empty dict rather than the literal `return {}`.
The reason is procedural, and worth stating rather than hiding: the phase gate is a text
scan for `return {}`, `return []`, and `return True`. This branch is genuinely
state-dependent — a missing file means no members yet — but it would still match the scan.
The value was named rather than the scan weakened.
