## Discrepancy recorded, not silently resolved

Order 2 phase 5 refers to "the nine stages of §7". The text of §7 in
`CIVILIZATION_GENESIS_SPECIFICATION.md` names **ten**:

```
Proposal → Architectural Analysis → Impact Analysis → Compatibility Analysis
   → Security Review → Governance Approval → Migration Plan
   → Implementation → Tests → Promotion
```

All ten are implemented, because the founding document is the authority and the order's
count appears to be an arithmetic slip. Dropping a stage to match a count would have meant
choosing which safeguard to discard. This is flagged here for the human to correct if the
intent was different.

## Decision 1 — Governance approval is counted, never asserted

`Proposal.advance("governance_approval", ...)` refuses unless an attached `Poll` actually
tallies to approved. There is no parameter, flag, or code path by which a stage record can
claim approval that the ballots do not support. The reverse is also blocked: the executive
agent cannot record a rejection over an approving vote.

## Decision 2 — Only humans may vote, enforced at two points

`Poll` refuses a non-`human:` voter both when building the eligible roll and when casting.
§8 forbids the executive agent from taking a governance decision on behalf of governance
"even formally, even in test data" — so this is enforced in the mechanism rather than left
to discipline.

## Decision 3 — Silence is never consent

An uncast poll tallies to `pending`, and a poll below quorum tallies to `no_quorum`.
Neither can satisfy governance approval. There is no timeout, no default approval, and no
"approved unless objected". Article III forbids automated amendment, and a rule that
passes because nobody spoke is an automated amendment.

## Decision 4 — A tie does not carry

Approval requires `for > against` strictly. An evenly split civilization has not decided.

## Decision 5 — Every stage must produce evidence, enforced by the pipeline

`advance()` raises if `finding` or `evidence` is blank. Order 2's rule — every step must
produce something concrete, never "done" without a trace — is enforced by the code rather
than by the author's intention.

## Decision 6 — The proposal stops at the human, deliberately

The real proposal, PROP-2026-08-09-002, proposes activating `population` as a fourth
institution. It passed five stages with genuine analysis and was then refused advancement
by its own pipeline for lack of ballots. That refusal is the phase 5 evidence.

Note what this means honestly: the ten-stage traversal is demonstrated **end to end in the
test suite** with synthetic human voters, and the **real** proposal is stopped at stage 6
awaiting the actual human. Reporting a complete real traversal would have required the
agent to cast a human's vote, which §8 forbids.

## Decision 7 — Security review produced a real finding, not a rubber stamp

The review identified that `set_lifecycle` over the protocol would allow an institution to
mark an agent stopped without engaging the kill switch — a stop that does not stop, since
the loop consults `safety/`, never the registry. The finding is attached to the proposal as
a binding condition on any future implementation. A review that finds nothing is not a
review.
