# PROP-2026-08-09-002 — Activate `population` as the fourth institution

**Raised by:** human:operator  
**Status:** open  
**Stages completed:** 5 of 10

## Summary

`population/` currently contains working code (`census/`, `lifecycle/`) written in Order 2 phase 3, but it is not an activated institution: it has no protocol address, no declared authority, and no entry in `institutions/runtime/activation.py`. This proposal asks governance to activate it as the fourth institution, giving it authority over the count and lifecycle state of agents, and an address for `census` and `set_lifecycle` actions in `protocols/institution/requests/`.

Raised in accordance with Order 2 phase 5, which requires one proposal to traverse the §7 pipeline. Order 2 also forbids implementing the result. This proposal is therefore carried to the point where a human decision is required, and stops there.

## Binding condition attached at security review

If this proposal is ever approved, `set_lifecycle` must either be omitted from the
protocol vocabulary or be made to engage `safety/`'s kill switch for the affected agent.
Marking an agent `stopped` in the registry does not halt its loop — the loop consults the
kill switch, never the registry. A stop that looks like a stop but does not stop is worse
than no stop at all.
